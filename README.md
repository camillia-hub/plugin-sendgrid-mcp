# SendGrid MCP

Sends and tracks email with SendGrid. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/sendgrid-mcp

Installs from the Camillia hub as `sendgrid-mcp-a6306f`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
